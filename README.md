# VAE Epidemic Modelling

This project explores parameter inference for a stochastic household SIR model.

I first built a household epidemic simulator and used ABC-MCMC as a baseline. I then trained a VAE on simulated epidemic data to learn latent representations related to model parameters.

## Methods
- Household SIR simulation
- ABC-MCMC
- Variational Autoencoder (VAE)
- Parameter inference and evaluation

## Tools
Python, PyTorch, NumPy, Pandas
